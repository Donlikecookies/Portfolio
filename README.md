# Personal Portfolio & Management System (Django)

This repository contains the semester-long personal portfolio project, updated progressively through Quiz 1 to Quiz 6. It features a public-facing portfolio, dynamic project displays, inquiry forms, user testimonies, and a secure admin dashboard.

---

## Prerequisites

Ensure you have the following installed on your local machine:
- Python (version 3.10 or higher recommended)
- Git

---
